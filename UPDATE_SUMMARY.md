# P2PStream v1.23.0 - Обновление брокера и безопасности

## Что сделано

### 1. Обновлен Cloudflare Worker (cf-worker/worker.js)
**Добавлены функции:**
- **Shared-secret аутентификация** - требуется BROKER_SECRET в переменных окружения
- **Улучшенная.topicMatches функция** - блокирует опасные wildcards (*), разрешает '+' только в последнем сегменте личного ящика
- **Отслеживание голосовых каналов** - сохранение userId:channelId в clientId для будущей фильтрации по каналам
- **Логгер для отладки** - info/warn/error логирование в консоль Worker
- **Улучшенная обработка CONNECT** - парсинг username/password, проверка секрета

### 2. Обновлены настройки (settings.ts)
**Добавлены новые опции:**
- `brokerSecret` - поле ввода с генерацией и кнопкой "Поделиться"
- `privateStream` - переключатель приватного стрима  
- `allowedViewers` - поле для списка Discord ID зрителей

### 3. Обновлен движок (engine.ts)
**Добавлена поддержка:**
- `brokerSubscribeStream()` / `brokerUnsubscribeStream()` функций
- Фильтрация announce по `allowedViewers` в обработчике сигналов
- Подписка на stream-топик при просмотре стрима
- Отписка от stream-топика при прекращении просмотра

### 4. Обновлен UI (ui/Bars.tsx)
**Добавлена новая функция:**
- Кнопка "🔗 Пригласить" в HostBar для генерации ссылки-приглашения с brokerUrl + secret + streamId

### 5. Обновлен основной плагин (index.tsx)
**Добавлена новая команда:**
- `/p2p-share` - отправка красивого приглашения в текущий чат с инструкциями

### 6. Добавлена документация
- `IMPROVEMENTS.md` - подробное описание всех улучшений v1.23
- `PRIVATE_STREAMS.md` - инструкция по использованию приватных стримов
- `QUICKSTART.md` - быстрый старт за 5 минут
- `TODO.md` - планы на будущее

## Как обновить Cloudflare Worker

Из-за ограничений MCP инструментов Cloudflare, пожалуйста,deploy обновленного worker вручную:

### Вариант 1: Через wrangler (рекомендуется)
1. Убедитесь, что у вас установлен wrangler: `npm install -g wrangler`
2. Войдите в аккаунт: `wrangler login`
3. Перейдите в директорию cf-worker: `cd cf-worker`
4. Обновите wrangler.toml, добавив переменную:
   ```toml
   [vars]
   BROKER_SECRET = "васгенерированныйсекрет"
   ```
5. Задеплойте: `wrangler deploy`

### Вариант 2: Через Cloudflare Dashboard
1. Перейдите в Workers & Pages → ваш worker → Edit code
2. Замените содержимое на обновленный worker.js из репозитория
3. В разделе Settings → Variables добавьте:
   - Name: `BROKER_SECRET`
   - Value: [васгенерированныйсекрет из настроек P2PStream]
4. Сохраните иdeployте

## Как использовать

### Для стримера:
1. В настройках P2PStream:
   - Включите "Брокер сигнализации"
   - Укажите адрес брокера (wss://<ваш-worker>.<аккаунт>.workers.dev/mqtt)
   - Нажмите "🔑 Сгенерировать" рядом с полем "Секрет для аутентификации к MQTT-брокеру"
   - Скопируйте полученный секрет
   - Включите "Приватный стрим" (рекомендуется)
   - (Опционально) Укажите Discord ID зрителей в "Список Discord ID зрителей"
2. Начните стрим как обычно
3. Нажмите "🔗 Пригласить" в панели хоста
4. Отправьте появившуюся ссылку другу

### Для зрителя:
1. Получите ссылку-приглашение от стримера
2. Нажмите на ссылку в Discord
3. Перезагрузите Discord (Ctrl+R)
4. Зайдите в голосовой канал со стримером
5. Нажмите "Смотреть" на пилюле стримера

## Преимущества обновления

### 🔒 Безопасность
- Защита от несанкционированного доступа к брокеру через shared secret
- Предотвращение атак через wildcards в tопиках
- Возможность аудита подключений через логирование

### 🎬 Конфиденциальность
- Возможность проводить truly приватные стримы только для приглашенных
- Гибкая система разрешений через список ID
- Уведомление о неправильном пароле при подключении

### 👥 Удобство
- Одноразовая генерация секрета через интерфейс
- Автоматическое применение настроек по ссылке
- Команда `/p2p-share` для быстрого приглашения в чат
- Кнопка "Пригласить" прямо в интерфейсе стримера

## Тестирование

Для проверки работы обновленного брокера:
1. Убедитесь, že BROKER_SECRET установлен в переменных окружения wrangler
2. Выполните health-check: запрос к `https://<ваш-worker>.<аккаунт>.workers.dev/` должен вернуть:
   ```
   P2PStream signaling broker is running. Connect with MQTT over WSS at /mqtt
   ```
3. Для полной проверки используйте тестовый скрипт:
   ```bash
   node cf-worker/test-mqtt.mjs wss://<ваш-worker>.<аккаунт>.workers.dev/mqtt
   ```
   Должно напечататься: `РАУНДТРИП OK`
